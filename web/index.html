核心技术特性

Blake3 极速秒传

上传前自动计算 Blake3 哈希，若服务端已存在对应对象，立即完成提交，实现零带宽瞬时秒传。

Tus 断点续传

基于标准 Tus 上传协议，支持网络中断后的进度恢复，大文件分片上传，单文件最大支持 5GB 上传。

C++ Epoll 高并发

底层使用 C++ 自研的 Reactor 多线程并发网络框架，无阻塞事件循环，提供极低的延时与极高的吞吐。

API 开发者集成配置

FileLink 基于哈希内容寻址与标准的 Tus 断点续传协议，支持使用命令行或任意 HTTP 客户端直接完成大体积对象发布。

1. 命令行分发文件 (秒传/直传)

发送标准的 POST 请求进行秒传探测，如果哈希命中则实现秒传落盘：

curl -X POST -H "Upload-Length: <file_size>" \
  -H "Upload-Metadata: filename <base64_name>" \
  http://127.0.0.1:18081/uploads

2. 下载私有文件

登录后，从“我的文件”中获取文件 ID；下载请求会由浏览器自动携带会话 Cookie：

curl -b "filelink_session=<session_token>" -OJ \\
  http://127.0.0.1:18081/files/<file_id>/download
