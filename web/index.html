核心技术特性

Blake3 极速秒传

上传前自动计算 Blake3 哈希，若服务端已存在对应对象，立即完成提交，实现零带宽瞬时秒传。

Tus 断点续传

基于标准 Tus 上传协议，支持网络中断后的进度恢复与大文件分片上传，单文件最大支持 10GB。

C++ Epoll 高并发

底层使用 C++ 自研的 Reactor 多线程并发网络框架，无阻塞事件循环，提供极低的延时与极高的吞吐。

文件名 操作

API 开发者集成配置

FileLink 使用内容寻址与标准 Tus 断点续传协议保存文件；上传和下载都需要有效的会话 Cookie。

1. 创建上传会话

发送 POST 请求创建会话；带上文件内容哈希时，服务端会尝试秒传。

curl -X POST -b "filelink_session=<session_token>" \
  -H "Upload-Length: <file_size>" \
  -H "Upload-Metadata: filename <base64_name>" \
  http://127.0.0.1:18081/uploads

2. 下载私有文件

登录后，从“我的文件”取得文件 ID；浏览器请求会自动携带会话 Cookie。

curl -b "filelink_session=<session_token>" -OJ \\
  http://127.0.0.1:18081/files/<file_id>/download
